# Software installation and access requests

## Install approved software
If you need an app such as Zoom, Microsoft Office or Slack on your work laptop, you can install it yourself from the Software Centre.
1. Open the **Software Centre** app on your work laptop.
2. Search for the app you need.
3. Select **Install** and wait for it to finish.
4. Open the app and sign in with your work email if it asks.

If the app isn't in the Software Centre, see the section on requesting access. If the install fails, raise a ticket through the helpdesk assistant or call the IT Service Desk on ext. 5111 (8am to 6pm, weekdays).

## Request access to software or a system
If you need a program or system that isn't in the Software Centre, or you can't open something your team uses, you need to request access.
1. Raise a ticket through the helpdesk assistant.
2. Name the software or system and say why you need it.
3. Your manager will be asked to approve the request.
4. IT will set it up, which usually takes 2 working days. You'll be told when it's ready.

You can't install unapproved software yourself. If the request is urgent, call the IT Service Desk on ext. 5111 (8am to 6pm, weekdays).
